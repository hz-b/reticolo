# RETICOLO

This repository contains two RETICOLO codebases:

- `V7-reticolo-blazr/` contains the v7 version of RETICOLO, with Matlab wrappers for grating design and related examples.
- `V9/` contains the v9 version of RETICOLO, including support for multilayer structures.

## Examples

The `Examples/` folder collects ready-to-run material for exploring the codebase:

- `Gratings/` contains scripts that build lamellar and blazed grating structures and export meshgrid visualizations.
- `Simulations/` contains complete RCWA runners together with precomputed results and plots.
- `Optical_Constants/` contains refractive-index data files used by the examples.
- `Reference_Data/` contains experimental and third-party benchmark data for comparison.
- `helpers/` provides shared Matlab utilities used by the example runners.
