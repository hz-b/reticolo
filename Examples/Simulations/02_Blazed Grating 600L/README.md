# Blazed Grating 600 l/mm

Physical HORIBA 600 l/mm blazed grating measured at HZB/ELISA. Compare against `../../Reference_Data/HORIBA_ELISA_Experimental/`.

Geometry: blaze 0.73°, anti-blaze 5.60°. Stack: 31 nm Au + optional 0.8 nm C on Si.

Result sets in `Results/`:
- root — TE, C_ff = 1.5, clean
- `TM_1,5cff_C_top layer` — TM, C_ff = 1.5, contaminated
- `TM_2.25cff_C_top_layer` — TM, C_ff = 2.25, contaminated
- `TM_2deg_C_top_layer` — TM, α = 2°, contaminated
- `TM_4deg_C_top_layer` — TM, α = 4°, contaminated
